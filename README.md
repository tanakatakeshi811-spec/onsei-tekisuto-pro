# ONsei TEkisuto Pro

Windows / Mac 常駐の音声ディクテーション&翻訳ツールです。

- ホットキー(既定 F8)を押すと録音開始、もう一度押すと停止 → 文字起こしして、
  今フォーカスしているアプリに自動で貼り付けます
- 録音中はリアルタイムに文字起こし結果が画面に表示されます
- 別のホットキー(既定 F1)で翻訳モード。日本語で話すと指定した言語に翻訳し、
  スピーカーから自動で読み上げます(相手にそのまま聞こえます)
- ESCキーでいつでも強制停止できます(貼り付け・読み上げも即座に中断)
- 文字起こし・音声認識はすべてこのPC内で完結します(faster-whisper)。
  誤字脱字の修正や翻訳にローカルAI([Ollama](https://ollama.com/))を
  使うこともできますが、無くてもルールベースの整形だけで動作します

## ダウンロード

[Releases](../../releases/latest) から、お使いのOS用のファイルをダウンロードしてください。

## ソースから実行する場合

```bash
pip install -r requirements.txt
python main.py
```

- Python 3.10 以上を想定しています
- 誤字脱字の修正・翻訳にAIを使いたい場合は [Ollama](https://ollama.com/) を
  別途インストールし、`ollama pull gemma3:4b` などでモデルを取得してください
  (無くても動きますが、AI整形/AI翻訳のチェックボックスがOFF相当の動作になります)

## 対応OS

- Windows 10 / 11
- macOS(Intel / Apple Silicon)

初回起動時、Macでは「アクセシビリティ」権限(グローバルホットキー・自動貼り付けのため)と
「マイク」権限の許可が必要です。システム設定の通知に従って許可してください。
