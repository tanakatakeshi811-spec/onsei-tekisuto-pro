# NekoVoice Pixel

Windows / Mac 常駐の音声ディクテーション&翻訳ツールです。

- ホットキー(既定 F8)を押すと録音開始、もう一度押すと停止 → 文字起こしして、
  今フォーカスしているアプリに自動で貼り付けます
- 録音中はリアルタイムに文字起こし結果が画面に表示されます
- 別のホットキー(既定 F1)で翻訳モード。日本語で話すと指定した言語に翻訳し、
  スピーカーから自動で読み上げます(相手にそのまま聞こえます)
- ESCキーでいつでも強制停止できます(貼り付け・読み上げも即座に中断)
- 文字起こし・音声認識は既定ですべてこのPC内で完結します(faster-whisper)。
  誤字脱字の修正や翻訳にローカルAI([Ollama](https://ollama.com/))を
  使うこともできますが、無くてもルールベースの整形だけで動作します
- 「Google音声認識を使う」をONにすると、確定時の文字起こしをGoogleの音声認識に
  切り替えられます(要ネット接続。音声がGoogleに送信されます。既定はOFF)
- 「辞書」ボタンから、名前などよく間違えられる単語を登録できます。認識結果の
  似ている部分を登録した表記に自動で寄せます(確定後にテキストを直接書き換えると、
  変更した箇所が自動でも登録されます)
- 「履歴」ボタンで、過去1時間に確定した文字起こし・翻訳結果を一覧表示・個別削除できます
- 「小」ボタンでコンパクト表示に切り替え(小さいインジケータ+状態文字だけの
  最小表示になります)。もう一度押す、またはコンパクト表示自体をクリックすると
  元の表示に戻ります

## ダウンロード

[Releases](../../releases/latest) から、お使いのOS用のファイルをダウンロードしてください。

## ソースから実行する場合

```bash
pip install -r requirements.txt
python main.py
```

- Python 3.10 以上を想定しています
- 誤字脱字の修正・翻訳にAIを使いたい場合は [Ollama](https://ollama.com/) を
  別途インストールし、`ollama pull gemma3:4b` などでモデルを取得してください
  (無くても動きますが、AI整形/AI翻訳のチェックボックスがOFF相当の動作になります)

## 対応OS

- Windows 10 / 11
- macOS(Intel / Apple Silicon)

初回起動時、Macでは「アクセシビリティ」権限(グローバルホットキー・自動貼り付けのため)と
「マイク」権限の許可が必要です。システム設定の通知に従って許可してください。

### Macで「アプリケーションは壊れています」と出る場合

現在このアプリは正式な署名(Apple Developer Programでの公証)をしていないため、
ダウンロードして開こうとするとmacOSのGatekeeperにブロックされ、
「"NekoVoicePixel.app"は壊れているため開けません」と表示されることがあります
(実際には壊れていません。公証されていないアプリをmacOSがこう表示するだけです)。
最近のmacOSでは、これに対する「右クリック→開く」の回避策も効かなくなっています。

以下のどちらかの方法で開いてください。

**方法A(ターミナルを使わない):**
1. 一度ダブルクリックして、ブロックのダイアログを表示させる
2. 「システム設定」→「プライバシーとセキュリティ」を開く
3. 画面の下の方に「"NekoVoicePixel.app"は使用がブロックされました」といった
   表示が出ているので、その横の**「このまま開く」**を押す(要パスワード)

**方法B(ターミナルを使う場合。すぐ効きます):**
```bash
xattr -cr /path/to/NekoVoicePixel.app
```
(`/path/to/` の部分は実際に展開した場所に置き換えてください。ダウンロード後に
ついた「隔離」の印を外すコマンドです)

### Windowsで「WindowsによってPCが保護されました」と出る場合

こちらも同じ理由(コード署名をしていないため)で表示される、実行前の確認画面です。
「詳細情報」→「実行」の順に押せば起動できます。
