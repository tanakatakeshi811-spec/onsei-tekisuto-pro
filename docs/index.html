できること

  • ホットキー1つで録音開始・停止。話した内容を今使っているアプリに自動で貼り付け
  • 録音中はリアルタイムに文字起こし結果を表示
  • 別のホットキーで翻訳モード。話した日本語を翻訳し、自動で読み上げ(相手にそのまま聞こえます)
  • ESCキーでいつでも強制停止
  • 音声認識・文字起こしはすべて端末内で完結(外部サーバーに送信しません)

起動できない時は

未署名(公証なし)のアプリのため、初回起動時にブロックされることがあります。 悪意のあるファイルではありませんので、以下の方法で開いてください。

Macで「"NekoVoicePixel.app"は壊れているため開けません」と出た場合

  • 方法A: 一度ダブルクリックしてブロック画面を出す →「システム設定」→ 「プライバシーとセキュリティ」を開く → 下の方に出る 「このまま開く」を押す(要パスワード)
  • 方法B(ターミナル操作): xattr -cr /path/to/NekoVoicePixel.app を実行(/path/to/は実際に展開した場所に置き換え)

Windowsで「WindowsによってPCが保護されました」と出た場合

  • 「詳細情報」→「実行」の順に押せば起動できます

展開(zip解凍)して中の実行ファイルを起動してください。
Macでは初回起動時に「アクセシビリティ」「マイク」の権限許可が必要です。
